# CrossPanel public samples

Four questions from the 2,650-question benchmark, with the original displayed option order. Each line of [questions.jsonl](questions.jsonl) contains the public question ID, task structure, relative image path, and complete model-facing prompt. [answers.json](answers.json) is used only by the scorer.
